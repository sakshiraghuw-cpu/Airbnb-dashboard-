# Airbnb Global Performance Dashboard

## Project Overview
The Airbnb Global Performance Dashboard is an end-to-end Power BI project designed to analyze listing performance, pricing trends, customer reviews, host activity, and market growth across multiple cities. The dashboard transforms raw Airbnb data into actionable insights through interactive visualizations, advanced DAX calculations, and data modeling techniques.

## Objectives
- Analyze Airbnb listing growth and market trends over time.
- Understand host and property distribution across cities.
- Evaluate customer trust and satisfaction using ratings and reviews.
- Identify seasonality patterns and booking trends.
- Compare property types, room categories, and pricing strategies.
- Discover key business drivers using Pareto and trend analysis.

## Key Features
- Interactive KPI cards for Listings, Hosts, Cities, Property Types, and Reviews.
- Listing lifecycle analysis to track growth, maturity, decline, and recovery phases.
- Pricing and revenue trend analysis across different markets.
- Customer review and rating insights for trust measurement.
- Property-type and room-type performance comparison.
- Time intelligence and seasonality analysis using DAX measures.
- Dynamic filtering for deep-dive exploration.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
- Interactive Visualizations

## Dashboard Insights
- Identified periods of rapid Airbnb listing expansion and market slowdowns.
- Analyzed the impact of external events on listing growth trends.
- Evaluated the contribution of different room types to overall inventory.
- Measured customer engagement through review volume and ratings.
- Highlighted pricing and demand patterns across locations.
